# Imágenes, tipografía y licencias — versión 4

## Fotografía principal

La imagen `public/images/hero-renovables.webp` es una creación original generada para este proyecto con el objetivo de representar un parque solar con profesionales y aerogenerador, inspirada en la composición que compartió el titular. No se ha extraído ni distribuido una fotografía del pack comercial Divi. No presenta personas reales identificadas, clientes o testimonios del portal.

Las versiones `aerogenerador.webp`, `paneles-solares.webp` y `equipo-renovables.webp` son recortes del mismo recurso original y **no constituyen fotografías documentales o imágenes de productos concretos**. Se emplean únicamente como soporte visual ilustrativo y su carácter debe respetarse en el texto alternativo.

Los recursos visuales están almacenados dentro de `public/images/` en WebP para servirlos desde GitHub Pages sin llamar a un proveedor fotográfico externo. No hay fuentes tipográficas empaquetadas.

## Fuente tipográfica

Se utiliza `DM Sans` solicitada a Google Fonts con alternativas del sistema. Antes de publicar, evaluar la carga desde Google Fonts en el aviso de privacidad y/o sustituirla por tipografías del sistema. No se distribuye ninguna fuente en este proyecto.

## Referencia estética

Fuente de análisis visual: captura proporcionada por el usuario de `https://layouts.divi-templatespro.com/divi-solar-energy-layouts-pack/` (Divi Solar Energy Layout Pack). La implementación es código HTML/CSS propio en Astro y no incluye archivos de Divi, logos de clientes, CSS o componentes comerciales originales.
